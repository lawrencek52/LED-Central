# Sound clips

Served by the backend at `/sounds/<file>` for LAN audio streamers to fetch (see
`src/application/thunder-service.js`). Only add clips whose license allows
redistribution in this repository.

| File | Used by | Source / license |
| - | - | - |
| `thunder.wav` | Halloween lightning (ThunderService) | "Closeup Thunder Strike 01" by loganzsound, https://freesound.org/people/loganzsound/sounds/840628/ - Creative Commons 0. 14 s, 24-bit 44.1 kHz stereo; about 0.5 s of near-silence before the crack, so playback can start with the flash. |
| `thunder-dim.wav` | Halloween lightning while the strips are dimmed by the nightly schedule | `thunder.wav` scaled by -10 dB (same source and license). |
